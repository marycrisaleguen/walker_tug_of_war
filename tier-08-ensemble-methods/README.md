## Why This Tier Matters

Ensemble methods dominate structured/tabular data competitions. Random forests and gradient boosting are often the first (and sometimes the last) algorithm to try on real-world datasets.

---

## Learning Outcomes

After completing this tier you will be able to:

- Build and tune random forests and gradient boosting models
- Understand when bagging vs. boosting is more appropriate
- Implement model stacking pipelines
