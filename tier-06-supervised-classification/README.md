## Why This Tier Matters

Classification is the most common ML task in practice — spam detection, disease diagnosis, image labeling. These three algorithms span the full spectrum from probabilistic linear models to non-parametric lazy learners.

---

## Learning Outcomes

After completing this tier you will be able to:

- Implement and interpret logistic regression outputs as probabilities
- Build and prune decision trees to prevent overfitting
- Apply KNN and understand its scalability limitations
