## Why This Tier Matters

CNNs are the backbone of computer vision. Object detection, medical imaging, autonomous driving, face recognition — all rely on convolutional architectures.

---

## Learning Outcomes

After completing this tier you will be able to:

- Design CNN architectures from scratch for image tasks
- Apply data augmentation to improve generalization
- Fine-tune a pretrained model for a custom vision task
