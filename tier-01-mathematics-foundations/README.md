---

## Why This Tier Matters

Machine learning is applied mathematics. Linear algebra is the language of data (tensors and weight matrices), calculus drives optimization (gradient descent), and probability theory underpins how models make predictions and quantify uncertainty.

---

## Learning Outcomes

After completing this tier you will be able to:

- Perform vector and matrix arithmetic by hand and in code
- Compute gradients and understand how they guide optimization
- Reason about probability distributions and conditional probabilities
- Apply Bayes' Theorem to real problems
