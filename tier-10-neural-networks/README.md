## Why This Tier Matters

Neural networks power the most impressive AI applications today. Understanding them from first principles — how a neuron fires, how gradients flow backward, what activation functions do — is essential before working with frameworks.

---

## Learning Outcomes

After completing this tier you will be able to:

- Implement a multi-layer perceptron from scratch in Python
- Derive and apply the backpropagation algorithm
- Choose appropriate activation functions for different layers
