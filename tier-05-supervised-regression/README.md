## Why This Tier Matters

Regression is the most fundamental supervised learning task. Understanding linear regression deeply — its loss function, optimization, and assumptions — gives you the intuition to understand nearly every other ML algorithm.

---

## Learning Outcomes

After completing this tier you will be able to:

- Derive and implement linear regression from scratch
- Recognize when a model is overfitting and apply regularization
- Tune regularization hyperparameters with cross-validation
