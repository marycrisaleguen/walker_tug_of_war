# ML Mastery Curriculum

A comprehensive, self-paced curriculum for mastering Machine Learning from the ground up. This curriculum is organized into **15 progressive lesson tiers**, each containing multiple units with topics, exercises, and Q&A.

## How to Use This Curriculum

1. **Follow the tiers in order.** Each tier builds on knowledge from previous ones.
2. **Read the unit topics** to understand the core concepts.
3. **Complete the exercises** in each unit to reinforce your understanding.
4. **Test yourself** with the Q&A sections before moving to the next unit.
5. **Revisit earlier tiers** whenever you need to refresh your foundational knowledge.

---

## Prerequisites

- Basic high school mathematics (algebra, functions)
- Curiosity and persistence!

No prior programming or ML experience is required — Tier 1 and Tier 2 will bring you up to speed.

---

## Recommended Tools

- Python 3.9+
- Jupyter Notebook or JupyterLab
- `pip install numpy pandas matplotlib scikit-learn tensorflow torch`
